# MyBB_Plugin-MyLists


 /*******************************************************************
 *
 *  MyLists plugin
 *  Authors: Joe Cotton & Vintagedaddyo
 *  
 *
 *  This plugin creates a global 'todo' list page.
 *
 ********************************************************************/
 
 *** INSTALLATION ***
 
 1. Simply upload the contents of the upload folder into your mybb root directory
 2. Then log into your admin cp and navigate to plugins on the 'Quick Access' sidebar on the left hand side.
 3. Enable 'My Lists'.
 
 *** Use ***
 
 * To use My Lists, go to your usercp and in the 'Miscellaneous' section, click 'Global Todo Lists'. This will take you to the mylists page.
 * Click 'Add a new todo' at the bottom of the table to add a new todo.
 * In the ACP, set a MyLists adminstrator by typing the user's username.
 * The MyLists administator can then click 'Remove' on the right hand side to delete the todo.
 
 *** Note ***
 
 This todo list is global. That means any logged in user can add a new todo, but only the MyLists administrator can delete them.
